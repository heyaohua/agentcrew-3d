## 办公室生活感 dev.3 — 2026-11-06

继续保留工作区、共享休息区和真实状态规则，本轮重点是让人物动作看得清、员工认得出。

### 内容

- 新增全景、工作区、休息区和员工近景按钮；先点选员工，再近看，可跟随其移动。重复点击同一按钮可重新取景。
- 拖动或缩放后进入自由视角，普通状态轮询及员工消失／恢复不会夺回镜头；显式切换员工或点击镜头按钮恢复跟随。自动跟随的员工退场时回到全景。
- 默认显示固定短编号，悬停、选中或切换详细名牌可查看身份；保留状态点。名牌锚点固定，避免悬停展开时跳动。
- 缩小区域标记，工具栏和提示随窗口宽度换行；尊重系统减少动态偏好。
- 沿用只读观察模式，没有新增控制接口或修改 Hook。

### 验证

- 独立代码复核通过；42 项观察模型、生活动作、镜头意图、寻路、座位和 2D 回归通过。TypeScript、修改范围 ESLint、Webpack 生产构建、差异空白检查通过。
- 可见 Chrome 的隔离模拟验证通过：四种取景、手动镜头中断与数据轮询、目标消失／恢复、切换员工、名牌切换、680/390 像素窗口、2D/3D 切换、减少动态偏好和退场回全景；页面错误为空。首次候选复现了 680 像素提示重叠，最终候选已修复并复验。
- 已切换真实局域网观察入口，并用可见 Chrome 核验工作／休息取景、动作开关及 2D/3D 切换；控制台错误为空，真实状态中没有隔离演练记录。截图已人工检查。
- 模拟数据仅用于独立临时服务，未写入真实观察接收器。本轮未新增真实 CLI Hook 全链演练，也不代表实体手机或真人长时间观感验收。

### 构建与回退

产物 `.next-office-life-dev3`，Build ID `pb0tr_LgKMPW5YDagRunW`；dev.2 和更早目录保留。

```sh

```

## 办公室生活感 dev.2 — 2026-11-06

用户确认现有工作区／共享休息区整体方向，要求继续增加欢乐感和团队认同，并明确要求开工。沿用当前布局及只读状态契约，本轮采用温暖、自然的小动作，不增加虚构业绩、验收成功或终端控制。

### 内容

- 3D 工作人物有打字、查看屏幕、托腮的装饰动作；固定身份决定三种节奏与色彩。动作不表示真实内部推理或绩效。
- 新出现的工作人物短暂招手；屏幕上正在工作的人收到真实结束状态后，可伸展约两秒再离场。默认隐藏历史时保留最多三秒的视觉过渡，不增加工作人数、不重放旧记录；断线、未知、复工、工位复用会立即取消过渡。
- 休息人物有举杯、看棋、轻摆腿和转头动作；等待时举手，错误／中断时保持关注姿势，不演出庆祝。
- 工位加入固定色彩杯子与小盆栽。工作区仍保持一人一电脑，共享休息区没有新增电脑或重复私人家具。
- 团队近况翻译真实事件，注明月日时间；未知／离线标明最后记录。Shell 事件仅表示执行命令，工具返回不表示测试成功。
- 点击人物或近况可查看员工档案；有已知父子关系且两人均在场时显示连线。档案放到侧栏前部，长事件列表单独滚动。
- 生活动作可关闭，默认尊重系统减少动态偏好。2D 保持原有动作与布局，共用档案和近况。

### 验证

- 独立代码审查及 45 项相关测试通过：观察模型／寻路／座位／收工／未知／装饰动作 36 项，语音上传回归 9 项。
- TypeScript、修改范围 ESLint、`git diff --check`、Webpack 生产构建通过。
- 可见浏览器隔离演练检查工作／休息、等待与错误、父子连线、档案、收工、未知空场景、动作开关及 2D 切换。演练仅使用临时服务和模拟快照，未写入真实接收器。
- 本机真实观察接口保持公开只读，核对无模拟记录。实际局域网页面的引用资源均为 HTTP 200；可见 Chrome 已核验真实页面、动作开关和 2D／3D 切换，控制台错误为零。内置浏览器的隔离演练成功，在线页连接超时后改用可见 Chrome 完成在线核验。
- 本轮未修改 Hook 或增加真实 CLI 子任务演练；此前原生 Hook 链路的验证限制继续适用。未进行真人长时间观感验收或手机验收。
